## Introdução

O objetivo principal deste projeto é fornecer uma API REST capaz de receber uma URL, armazená-la em um banco de dados e, caso ela receba uma chamada, redirecionar para a URL original.

## Funcionalidades

- Encurtamento de URL.
- Visualização da quantidade de acessos à URL.
- Integração com o banco de dados PostgreSQL.
- Documentação de cada endpoint utilizando Swagger.
